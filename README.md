# Simulations of life history variation for demographic inference from population genomic data

### Code and supporting files

This repository contains the following files:
- [SLiM](https://messerlab.org/slim/) script for genetic simulations of life history - access here!
- Table S1 - Information on data availability and sampling locality for the sequences utilized as a case-study  - access here!
- [iPyrad](https://ipyrad.readthedocs.io/) script utilized for reference genome mapping of the empirical dataset utilized as a case-study - access here!
