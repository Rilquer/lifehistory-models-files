# Simulations of life history variation for demographic inference from population genomic data

### Code and supporting files

This repository contains the following files:
- [SLiM Script for genetic simulations of life history](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/lh-script.slim)
- [Model parameters, population parameters and summary statistics utilized for Random Forest models](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/logstats.zip)
- [Table S1: Information on data availability and sampling locality for sequences utilized as a case-study ](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/tableS1.csv)
- [Script for reference genome mapping of the empirical dataset utilized as a case-study](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/params-species.txt)
- [Dataset of empirical summary statistics for case-study species](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/emp_stats.csv)
- [R script for Random Forest model](https://github.com/Rilquer/lifehistory-models-files/blob/main/Files/random_forest.R)
